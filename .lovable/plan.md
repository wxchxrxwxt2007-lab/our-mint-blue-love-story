# เชื่อมคูปองและข้อความเข้าฐานข้อมูล + หน้าแอดมินลับ

## สิ่งที่จะได้
- ข้อความที่แฟนส่งจะถูกบันทึกลงฐานข้อมูลทันที
- คูปองที่กดใช้จะบันทึกลงฐานข้อมูล ไม่ว่าเปิดจากเครื่องไหนก็ขึ้นว่าใช้สิทธิ์แล้ว
- หน้าลับ `/admin` (และปุ่มเล็กๆ ซ่อนไว้ท้ายเว็บ) ต้องใส่รหัสเจ้าของเว็บก่อนเข้า
  - กล่อง 1: ข้อความจากแฟน พร้อมวันเวลา
  - กล่อง 2: ประวัติการใช้คูปอง พร้อมวันเวลา + ปุ่มรีเซ็ตทีละใบ และรีเซ็ตทั้งหมด
- ตกแต่งหน้าแอดมินในธีมมิ้นต์-พุดดิ้งเดียวกัน

## รายละเอียดทางเทคนิค
- ตาราง `love_messages` (id, message, created_at) และ `used_coupons` (id, coupon_title unique, used_at) เปิด RLS ไว้และไม่ให้สิทธิ์ใดๆ กับผู้เข้าชม ให้เข้าถึงได้เฉพาะผ่านฝั่งเซิร์ฟเวอร์เท่านั้น
- ฟังก์ชันฝั่งเซิร์ฟเวอร์สำหรับคนทั่วไป: `sendMessage` (จำกัด 1–500 ตัวอักษร), `useCoupon` (เฉพาะชื่อคูปองที่มีอยู่จริง), `listUsedCoupons` (ส่งกลับแค่ชื่อคูปอง)
- ฟังก์ชันของแอดมิน: `adminLogin`, `adminData` และ `adminResetCoupon` จะตรวจรหัสผ่านที่เก็บเป็นความลับบนเซิร์ฟเวอร์ (`ADMIN_PASSWORD` = รหัสที่เลือกไว้) ด้วยการเทียบแบบปลอดภัย และจะจำว่าเข้าสู่ระบบแล้วด้วยคุกกี้เซสชันที่เข้ารหัส (`SESSION_SECRET`)
- หน้าหลักจะอ่านสถานะคูปองจากฐานข้อมูลแทนข้อมูลที่เก็บในเครื่อง ส่วนแชตจะแสดงข้อความที่ส่งในเครื่องนั้น
- ย้ายรายชื่อคูปองไปไว้ในไฟล์ที่ใช้ร่วมกัน และเพิ่มการทดสอบสำหรับการตรวจชื่อคูปอง
