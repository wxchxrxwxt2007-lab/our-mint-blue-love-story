# เว็บครบรอบ 2 เดือน Saynam (ธีม Hangyodon x Pompompurin)

## ลำดับหน้าจอ
```text
Countdown Lock (ถึง 29 พ.ย. 2026 06:00 เวลาไทย) -> Secret Passcode (280869, คำใบ้ "คุยกันวันแรก") -> แอนิเมชันปลดล็อก -> หน้าหลัก
```

## ดีไซน์
- โทนสีฟ้ามิ้นต์ เทอร์ควอยซ์ เหลืองครีมพุดดิ้ง น้ำตาลคาราเมล ไม่มีสีชมพูเลย
- ฟอนต์โค้งมนน่ารัก (Mali สำหรับภาษาไทย + Fredoka)
- ไอคอน 2D ลายเส้นวาดมือ (พุดดิ้ง หมวกเบเร่ต์ ปลาหมึก ฟอง ดาว) และฟองอากาศลอยเบาๆ ทั้งหน้า
- ออกแบบให้ดูบนมือถือเป็นหลัก

## หน้าหลัก (เรียงจากบนลงล่าง)
1. ส่วนต้อนรับ: หัวใจ 3 มิติที่สร้างจากคำว่า "LOVE" หลายคำ หมุนช้าๆ สลับสีฟ้า/เหลือง เรืองแสง แตะแล้วเต้นตุบๆ, ป้าย "2nd Month Anniversary", หัวข้อ "Our Story Continues... Saynam", ตัวนับเวลาที่คบกันมาตั้งแต่ 29 ก.ย. 2026
2. เกมทายใจ 3 ข้อ: เฉลยทันทีหลังเลือกคำตอบ นับคะแนนไว้ การ์ดสรุปผลจะแสดงข้อความตามคะแนน (3, 2, 1/0) พร้อมฟองอากาศและหัวใจ และมีปุ่ม "ลองตอบใหม่อีกครั้ง"
3. แกลเลอรีรูปแบบโพลารอยด์/ฟิล์ม 6 รูป มีแคปชันเหมือนซับไตเติ้ลและวันที่ (ใส่รูปตัวอย่างไว้ก่อน เปลี่ยนเป็นรูปจริงได้ง่ายๆ)
4. ซองจดหมายสีเหลืองติดสติกเกอร์มิ้นต์ กดแล้วเปิดอ่านข้อความ + ช่องพิมพ์ "ส่งบทพูดถึงเค้า" ที่โชว์ข้อความเป็นแชตแบบในซีรีส์
5. คูปอง 9 ใบสไตล์ตั๋วหนัง กด "กดใช้สิทธิ์" แล้วมีตราประทับ "ใช้สิทธิ์แล้ว! แคปหน้าจอส่งให้เค้าได้เลย"

## ไข่อีสเตอร์
- ปุ่มพุดดิ้งกับปลาหมึกเล็กๆ ซ่อนไว้ที่มุมจอ กดแล้วขึ้นป็อปอัป "เก่งมากที่หาเจอ! รางวัลคือจุ๊บ 1 ที 😘"

## รายละเอียดทางเทคนิค
- ใช้หน้าเดียว (index) มีสถานะ countdown -> lock -> main; เวลาปลดล็อกคือ 2026-11-28T23:00:00Z
- หัวใจ 3 มิติทำด้วย CSS 3D (preserve-3d) วางคำ LOVE ตามสมการรูปหัวใจในหลายชั้น ไม่ต้องลงไลบรารีเพิ่ม
- การใช้คูปอง ข้อความแชต และสถานะการปลดล็อกจะเก็บไว้ในเครื่อง (localStorage) จึงไม่ต้องใช้ระบบหลังบ้าน (ข้อความแชตจะเห็นแค่ในเครื่องของแฟนเท่านั้น)
- ข้อจำกัด: รหัสผ่านกับการล็อกเวลาทำงานในเบราว์เซอร์ ถ้าคนเขียนโค้ดเป็นก็เลี่ยงได้ แต่สำหรับเซอร์ไพรส์ถือว่าเพียงพอ
- ใส่ชื่อหน้าและคำอธิบายเว็บให้ครบ
